# TaskFlow – Employee Task & Issue Management System

## Project Overview
TaskFlow is a web-based Employee Task and Issue Management System designed to manage employees, organize tasks, monitor task progress, and track workplace issues.

This project is currently under development.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Java Spring Boot (planned backend)
- MySQL (planned database)

## Features Implemented
- Dashboard interface
- Sidebar navigation
- Employee management interface
- Add employee functionality
- Dynamic employee listing
- Responsive user interface

## Planned Features
- Edit and delete employees
- Task creation and assignment
- Task progress tracking
- Workplace issue management
- REST API integration
- Database connectivity
- Authentication and authorization

## How to Run the Project

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.
